# kelsimas

Portfolio site for Kely Simas, brand & experience designer. Static HTML/CSS, bilingual (EN/PT), deployed on Netlify.

- `index.html` – content (each text has a `data-en` and a `data-pt` version)
- `styles.css` – design
- `netlify.toml` – keeps the site out of search engines until it is approved (remove the headers block and the robots meta tag to go public)

Images are currently loaded from Kely's Flickr; move them into `/img` before launch.
